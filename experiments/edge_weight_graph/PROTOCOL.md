# 稀有边权重与首动作排序 · 运行前冻结协议

本轮只对合成图训练。读入统一诊断的指标定义，不访问或更新真实环境 checkpoint。主判定使用表格全局证书；IQE 是固定架构和有限求解预算的对照。此前未运行本图的任何实验组。

1. 节点顺序 s,a,u,b,v,g。七条有向边依次为 sa,au,ug,sb,bv,vg,gs。成本除 vg 为 1+Δ 外均为 1。Δ 取 1、2；每档内唯一干预参数 q 依次为 1/7、0.01、0.001、0.0003、0.0001、0.00003、0.00001、0.000001。ug 权重 q，其他六边各 (1−q)/6。五个非终节点到 g 的推远项始终等权 1/5。七条边在每次完整评估与约束计算中均出现。g 的唯一出边参与学距离和强连通性，执行在首次到达 g 停止。
2. 表格变量为完整 6×6 有向矩阵，非负、零对角、所有三角不等式。硬约束用线性规划，平均组用非负辅助变量 y，引入线性上界 dₑ≤cₑ+√(η/wₑ)yₑ 和单位二范数球，η=0.0001。直接优化矩阵。SciPy FP64，硬组 HiGHS LP，平均组 SLSQP 与球面支持平面形成的全局 LP 外界。平均目标另用分流路径上界和加长边 Dijkstra 可行矩阵独立夹逼最优值。返回满足约束且由全局界验证的矩阵；必要时用非负化、最短路径闭包和与可行表格解的凸组合消除数值噪声。输出各残差和真实原始目标值。全局推远目标证书宽度要求 ≤1e−7。
3. 近最优集合固定为原可行集与 F≥F*−1e−6 的交集。以其为约束分别优化 ±m。对每端保留可行见证和全局外界，外界考虑 LP 对偶的舍入与站立残差；每端夹逼宽度 ≤2e−5，否则标记未认证。SLSQP ftol=1e−13、最多 1200 次迭代；HiGHS primal/dual tolerance=1e−9；每个目标最多 1200 次支持平面精化。允许使用解析支持方向帮助求精，保留数值状态。表格局部/三角/零对角/非负可行残差审计上限 1e−8（平均平方超额 1e−11）。排序死区 ±1e−6，区间全负/全正以保守外界为准，跨零须有两侧可行见证。点并列单列；并列的首动作额外成本记录为区间 [0,Δ]，不按数组次序破局。
4. IQE 使用一个 6×64 可训练节点 embedding（等价于 one-hot 线性层）与 torchqmet.IQE(64,8) 官方默认可学习 maxmean reduction。CPU FP64、1 线程，torch seed=606，embedding 从 N(0,0.1²) 初始化；所有 18 个独立条件复制同一个初态，Adam 状态与乘子各自清零。硬约束每档 Δ 仅训练一次，与 q 无关，汇总时硬组平均平方违反按均匀权重报告。平均组每个 q 独立训练一次。
5. 每组固定 12000 次完整批次 Adam，β=(0.9,0.999)，eps=1e−8，零 weight decay，无采样或梯度裁剪。步索引 0–7999 学习率 0.01，8000–11999 从 0.01 指数衰减到 0.00001。优化 −F 加逐约束 PHR 之和，每项 (relu(λ+ρr)²−λ²)/(2ρ)。硬组 rₑ=dₑ−cₑ、ρ=20。平均组单约束 r=||√w·relu(d−c)||₂/0.01−1、ρ=1，与原平方预算有相同可行域。每 100 个 primal 步之后在新参数重算全部 r，令 λ←relu(λ+ρr)，训练期间不读取真距离或表格答案。固定终点不选优、不缩放修复。IQE 矩阵结构残差要求 ≤1e−8；硬边最大正违反 ≤1e−5 或平均平方 ≤η+1e−8 才记为对应约束可行。IQE 近最优按 F≥F*−1e−6 且可行单列报告。任何不满足约束的终点仍保留及绘图。
6. 若表格近最优集全正且对应 IQE 终点反序（不论其是否可行），加做该组监督见证。仍用相同架构和初始化，拟合已报告表格最优矩阵全部 36 项的等权 MSE，固定 12000 次同设置 Adam，再一次 FP64 L-BFGS-B（最多 1500 次迭代、ftol=1e−15、gtol=1e−12）。不再搜索架构或重启。分别报告拟合误差、对应可行性、F 与最优值差和排序；同时可行、目标近最优、排序正确才是任务表示见证。失败仅说明本次拟合没有提供见证。
7. 所有表格/IQE/监督终点记录 m=(1+Jb)−(1+Ja)、实际首动作与首次到 g 的真实额外成本、F、逐边原始距离和成本、最大违反及加权平方风险。两条真实最短后缀 a→u→g、b→v→g 计算带符号 H 与 T，核对 m=Δ+ΔH−ΔT（容差 1e−8）。保存近最优区间两端的矩阵与可行性；图按两档 Δ 分面、q 对数轴、显示零线和 IQE 终点可行性。报告分别判断全局表格、可行 IQE 和不满足约束的 IQE。
