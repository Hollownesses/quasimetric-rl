# 参数见证、数值实现与扫描恢复

本项只构造并评价参数点，不继续Adam训练。坐标变换后保留旧optimizer/RNG只为证明没有更新；这**不是**声称未变换的一二阶矩已成为新坐标下等价的可续训Adam状态。

OG首个32行、未统一JIT路径的梯度smoke没有通过严格对齐。随后按原1024批与JIT路径检查，value/dynamics相对L2误差约1.10e−6、6.33e−8，actor对这两模块梯度为0。正式采样流随后从seed4400重新开始；没有利用smoke状态或更新模型。

首次全量原模型扫描在D齐次性的相对误差阈值处停止，未计算查询目标或控制结果。后续先检查潜在状态/预测的坐标变换（相对误差约2e−7），再保留并使用实际重算的D。全量原模型D的相对L2齐次误差约5.4e−4，最大绝对差约2.6e−4；平均D差很小。区间排序/消去下，不能拿相对误差阈值替代实际目标值，更不能用a*D旧值冒充实际网络D。约束风险仍须实际全量通过，未放宽eps。

扫描按131072条转移分块保存。每块绑定实际参数树、动力学树、完整(s,s_next,action)数据摘要、数值kernel源码、batch大小、JAX版本与精度设置，并校验文件SHA。仅完整且身份一致的块可复用；没有缓存的早期失败扫描不能声称复用了结果。缓存不改变总体、候选、a或查询预算。

旧查询/新查询的统计范围另见STATISTICAL_NOTES.md。原/边界参数的实际控制使用FP32网络重新执行，不能把理论正缩放的argmin不变性当作已经执行的结果；raw历史回合及R0边界旧回合明确标记复用。
