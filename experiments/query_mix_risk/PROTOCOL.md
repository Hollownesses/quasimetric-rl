# PointMaze Medium 固定动作对的查询权重 × 平方预算实验

2026-11-06，训练与分支评分前固定。只用官方 Navigate seed 0 的 `params_100000.pkl` 和已有离线数据。实验单位是一对固定动作、一个目标和一条共享采样流。

## 固定探针与背景查询

Medium 地图中央环路选相隔六格的岔口 `(3,2)` 与目标格 `(6,3)`，使用格心 `s=(4,8)`、`g=(8,20)`。行列为官方地图的零基索引。固定 MuJoCo 初态含零速度。A 用动作 `(1,0)` 向 `(3,3)`，B 用 `(0,1)` 向 `(4,2)`。依次朝该侧后续格心执行，验证两条路线分别走完不同走廊并进入同一目标圆。四组只比较这两个动作，用相同初态的单步 `env.step` 后继。

- A 侧格序为 `(3,3) → (3,4) → (4,4) → (5,4) → (5,3) → (6,3)`。估价锚点 `z_A=(12,8)`。
- B 侧格序为 `(4,2) → (4,1) → (5,1) → (6,1) → (6,2) → (6,3)`。估价锚点 `z_B=(0,12)`。

从原训练轨迹中取第一格格心 1.5 单位内的起点。到同 episode 的下一次进入 `g` 的半径 1 成功圆，最多 256 步，连续重复格压缩后须与对应侧格序完全一致，且经过 `z_A` 或 `z_B` 的 1.5 单位邻域。每侧每 episode 取离第一格格心最近的合格起点，平局取较早行。用最小成本一对一匹配保留较小池全部记录，成本为起点到目标圆、锚点最近行到目标圆这两段步数差的绝对值之和，附加两种格心偏差的绝对差之和乘 0.001 用于打破步数平局。冻结原数据行号、证据和真实后继。两池的目标都为同一固定点 `g`，轨迹只用于确认走廊和到达，起点与固定评估起点、两个后继和两个估价锚点分开。

## 训练与实测约束

每个更新的推远损失用原函数 `p(d)=100*softplus(5-d/100)`。固定 50% 为官方原随机 value 查询批均值，5% 为同一个 `(s,g)`，45% 为所选一侧背景查询的全池均值。A 重与 B 重两种分布只交换最后 45% 的去向。局部风险仍为未经查询加权的 `mean(relu(d(x,x')-1)^2)`，使用同一批官方有效边。

四组从同一完整 100k 状态开始。每组 512 次 critic 更新，batch 256，共享原 E6 采样流 seed 2001。IQE、value Adam 状态和学习率 0.0003 沿用父模型，actor、latent dynamics 及对应 Adam 矩冻结。两个风险上限为 0.05 和 0.01。共同的短步求解器用 `push + λ R_batch` 更新 value，从原 λ 开始在 `log λ` 上做归一化对偶更新。公式为 `log λ += 0.01 * clip(R_batch / (0.85 * cap) - 1, -1, 1)`，两档都保留相同比例的采样余量。乘子采用这条独立的更新规则，原乘子 Adam 矩保留在 checkpoint 中。只取第 512 步，无参数投影。四组合计 2048 次更新，执行总上限 600 秒。

终点用实际网络扫描全部 100 万有效训练边，按 FP64 汇总实测 `R`。四组各自须满足名义上限，且两个紧组的最大 `R` 至少比两个松组的最小 `R` 低 0.001，否则预算对照判为无法判别。

## 预定读数与判据

报告两锚点的距离估价 `J_A=d(z_A,g)`、`J_B=d(z_B,g)`，以及用两个真实后继计算的 `Q̂_i=1+d(s'_i,g)` 和 `m=Q̂_B−Q̂_A`。每个预算内定义 `ΔJ_A=J_A(A重)−J_A(B重)`，`Δm=m(A重)−m(B重)`。用数值阈值 0.001，方向支持要求松预算下 `ΔJ_A>0.001`、`Δm<−0.001`。放大支持还要求紧预算下两项保持同向或接近零，并且 `ΔJ_A` 和 `−Δm` 均至少减少 0.001。另用同一批 2048 个官方验证查询的距离均值归一化 `m`，作为对整体距离尺度变化的敏感性核对。结论限定于固定探针和这一次配对续训。
