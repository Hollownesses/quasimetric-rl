# 联合准度量—到达流的第一阶段随机训练协议

2026-11-08，在查看本原型训练结果前冻结。仅研究既有六节点可控图。

- 图、边成本、边采样质量、两个查询混合沿用 objective_flow / gap_learning：sa,au,ug,sb,bv,vg,gs，除 vg=1.25 外成本为 1；p=1/7；两个 μ 为 (.05,.01,.92,.01,.01) 和 (.05,.01,.01,.01,.92)。g 为吸收目标。
- 距离是全部 30 个非对角表项，零对角固定，投影仅保证非负和所有三角不等式。六条非终点出边各有一个独立非负流变量；g 出边的到达流固定为 0，属于终止语义。没有守恒投影、已知路径混合、最优路径/价值/动作标签。
- 全部组初始距离为 1、每条可训练边流为 .1。距离投影由只含状态三元组的 NNLS 求解，完全不读取边成本、查询或流。它是相应对角度量下的投影，以匹配 Adam 更新，不采用欧氏投影替代对角度量投影。
- 主实验六组：两种 μ × 原 QRL、naive joint、unbiased joint。每组固定 20000 次更新、batch=256。仅使用既有采样 seed 2001，共用边序列和查询均匀随机数；两查询混合仅改变均匀数到查询的映射。不得更换 seed、挑选最好 checkpoint 或按结果增加更新。
- 新方案 λ=β=1。naive 对批均值 G、守恒向量 r 直接平方；unbiased 对两个平方均去掉自配对项，保留普通逐边风险均值。负的无偏估计不截断。FP64、Adam β1=.9、β2=.999、eps=1e-8，零 weight decay。前 12000 步 lr=.01，后 8000 步指数衰减至 .0001。仅投影准度量结构和流非负，不修复守恒。
- 原 QRL 使用线性推远和平均平方风险上限 .05，critic 使用同样优化器与距离结构。乘子从 1 开始，用 λ←max(0,λ+η_dual(R_batch−.05))，η_dual=.05 并与 critic 同比例衰减。报告真实风险和上限超出量，不事后修复。该基线是图上的 QRL 数学目标，不代表官方神经 QRL 的完整实现。
- 每 500 步保存原始变量与窗口平均采样损失，固定最后一步为结论终点。训练模块不调用策略评估、最短路、最优流或独立期望目标求解器；独立评估在训练结束后运行。
- 独立诊断：对 naive / unbiased 的精确期望目标各运行同预算、同初始化和同优化器的无采样对照（两查询共四组）。再直接求解完整 36 变量期望目标，包括只保留 gap 方差、只保留守恒方差的两个消融；这些参考解只用于解释结果，不给随机训练热启动、标签或参数调整。所有计算总墙钟预算 600 秒，超时保留未完成状态，不改预算追结果。
- 报告 G、R、真实 Bf−b 的 L2/L∞、逐状态残差、流成本 C(f)、归一化流策略真实期望成本、从固定 s 的成本、各起点到达概率、critic 贪心策略成本、三角/非负残差。策略评估通过原图的吸收链线性系统完成；零出流状态不插入默认动作，标为失败/无穷成本。原 QRL 没有学习流，其评估占用不混写成学得的守恒残差。
- 严格联合通过条件：proper；|G|≤.005；R≤1e-4；真实守恒 L∞≤.005；固定 s 的策略成本≤3.025（错误分支概率≤10%）；查询平均策略额外成本≤.005。该判据用于说明第一阶段是否完整成功，不按结果修改。另连续报告各项改善，不能只凭损失下降称成功。QRL 风险可行性单列实际差值。
- 梯度检查覆盖采样 naive / unbiased 的有限差分，以及 batch=2 时 35² 个独立样本组合的精确期望/梯度恒等式。守恒变量不可预先消去。失败后分析期望目标偏差、方差、局部条件数和策略提取，不增加额外训练技巧。
- 不启动真实环境训练，不运行官方 1M，不进行新 seed / 多 seed 复现。原始产物保留，研究结论只覆盖这一次配对可控图实验。
