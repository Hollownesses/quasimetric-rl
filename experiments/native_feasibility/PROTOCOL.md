# 原经验约束可行性与决策失败（计算前固定）

目的：区分“局部可行性不足”与“到目标的距离/决策未正确恢复”，不追加任何训练。仅用原 U R0 50k、OG 官方 seed0 100k，原网络结构、成本/目标、采样定义与控制器不变。正缩放是事后可行点构造，不宣称优化了原推远目标。

1. U 全42536物理记录、原每边 c。令 a*=min(1,min_{d_i>0} c_i/d_i)；若原模型不可行，a=a*×(1−1e−4)，否则 a=1。只缩放最终 projector 线性层的权重/偏置，利用当前无 transform/discount IQE 的正齐次性。全量重算实际网络所有物理边，要求 max(d_new−c)≤1e−5，保持目标 quotient 零值，核验其他参数不变及 d_new≈a*d。
2. OG 全100万有效训练转移（排除1000末行），原成本1、原 eps。计算真实全经验 R(a)=mean(relu(a*d_i−1)^2)。若 R(1)≤eps，a=1，保留原模型并复用已有50回合；否则 FP64 二分60次求最大可行 a*，取 a=a*×(1−1e−4)，仅缩放 phi 最后 Dense 层的 kernel/bias。实际网络再次全量重算，要求 R_new≤eps+1e−6，核验参数形状、其余叶、optimizer/count/RNG不变。保存 R(1)、a*区间、a、实际风险、最大违反及齐次误差；不改变 eps 或改成 U 的硬约束。
3. 选择 a 只读取训练转移与原成本，不读取参考、任务成败或评价点。a 确定后才评价。U 复用原58专家分支/483对及165起点图路径，执行原32地理起点×2 planner seeds、H10/N128/300步MPPI；另统计这些新实际轨迹上 d(s,s')−实际成本，以区分经验可行与连续访问可行。父64回合复用。
4. OG 的单位首步成本和正缩放在精确算术下不改变真实后继 argmin；不把浮点参数重实现冒充严格逐位恒等。若 a=1 且完整 agent 逐叶不变，则直接复用原0/50记录；若 a<1，实际缩放网络完整执行同50回合、121真后继、1000步，并记录首步候选排序与正缩放原分数的偏差/argmin差异。另保留 canonical 图峰差、IQR与严格下降可达性，后者容差按 a 同比缩放，防止尺度造成假并列。
5. 没有新的 actor 训练/评价；OG actor/dynamics不随 phi 重标定，因此只用真后继贪心隔离 critic。训练记录上的可行性不外推到连续所有状态；可行点不等于原目标最优点，也不反驳 QRL 理想最优性条件。无论成败均保留，模型/数值表/轨迹/审计留本地，只提交源码、测试、协议、报告和引用图。
