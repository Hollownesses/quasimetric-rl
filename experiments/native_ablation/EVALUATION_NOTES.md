# 评价补充

在仅观察到训练进度、尚无任何正式终点或评价结果时，增加尺度检查：U 保留全部非终图源的 J 均值、范围与参考偏差；OG 在原 canonical goal/anchor 的独立环境图上复用既有 graph_metrics，报告最小路线峰差、峰差/IQR、严格下降可达性和距离 IQR。这些指标不进入训练或终点选择，只用于区分 critic 数值尺度变化与路线排序变化。主评价预算与三组条件不变。

训练 smoke 内包含针对本消融的核验：U 各处理首步 dual 与原入口完全一致；OG 各处理首步非 value 参数（λ、dynamics、actor）与原入口一致到 1e−6，检查删去的项没有误改其他直接梯度通道。两步状态往返后全部丢弃，再从父状态和同一批次流正式开始。
