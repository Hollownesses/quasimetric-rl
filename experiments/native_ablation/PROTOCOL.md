# 原配方 512 步损失消融（运行前冻结）

本项在 c279ed0 的冻结点梯度结果之后提出，检验即时方向能否预测有限续训与执行；不作为新的独立训练 seed 或通用修复。两边均复用原网络和完整父 checkpoint，不将 OGBench 转成 U-trap 配方，不使用图参考、评价目标或动作排序标签训练。

1. 每环境三组：native 原损失；no_push 仅删除原 value 推远项（U 同时删 .6 task 和 .4 B1，OG 删原 softplus 项）；no_local 仅删除原 value 直接局部 primal 惩罚（U PHR、OG λ·mean(relu(dpos−1)^2)）。所有组继续各自原 dual 更新；OG 的 lam_loss、dynamics_loss、actor_loss 保留，所以 no_local 不等于完全没有局部表示学习。两项消融是诊断处理，不宣称仍在求解原优化问题。
2. 同父 R0 50k / 官方 100k、同完整 Adam 状态与计数、同环境内同批次流，每组固定 512 步，仅取终点。U 恢复终点 sampler、batch256、原逐访问 PHR dual 时钟、rho100、全部物理记录与 task+B1 查询，学习率固定为父终点 2e−7，不重新拉高。OG seed4400、batch1024、原 GCDataset 所有字段、原 rng 与联合 Adam，lr0.0003、eps与网络配置不变；前三十二批须与 c279ed0 的 stream 一致。跨环境预算单位不同，仅在各自三组内作因果比较。
3. 先做原状态两步 smoke，保存加载验证（随后丢弃，从原状态正式开始）；native 更新必须与原入口一致，原始 checkpoint 哈希始终不变。记录各组有限性、count、dual/lam变化、完整采样流及首32批流。正式只保存终点。无按结果选中间点、增预算或调参数。训练函数不读取参考值与诊断缓存。
4. 训练全部结束后独立评价：沿用 c279ed0 的58/50个预选动作对，报告初始错对及全部对的 Δm、修复/新增错序，不把 probe 训练效果冒充导航。U 同时评价全部58分支的严格483对、165个不同专家起点的图内贪心额外成本，以及原32地理起点×2 planner seeds 的64回合 MPPI（H10/N128、300步原上限、原cost与终止）。OG 同一50官方task3 reset、121真实MuJoCo后继、1000步原时限，报告完整首动作反序及真实后继贪心成功；绕过 actor/dynamics 的提取影响，不作为官方actor评分。父模型闭环结果复用，新增三组均完整执行。
5. 报告每组相对父模型及 native 的配对新增/失去，所有失败保留。局部违反（U全物理记录与去重边，OG100k验证边）单列；局部可行性下降不能冒充根因修复，消融改善也不能证明被删除项是唯一历史原因。只提交源码、必要测试、协议、报告和引用图；checkpoint、CSV/JSON/NPZ、轨迹、日志留本地。
