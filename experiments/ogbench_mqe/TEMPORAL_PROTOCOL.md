# MQE已有50k/100k模型的机制对照（2026-10-30）

只读取同一次训练的固定中点50k和正式终点100k，不选task3曲线峰值60k，不改变正式100k结果。不训练、不换seed复跑、不启动1M。整个评估设置360秒计算上限，若未完成则保留进度并停止，不自动扩预算。

- 复用既有25例bank。50k原生actor在全部25例完成官方1000步上限episode，100k actor复用已保存结果；用于判断同例执行是否有后期退化，不把中点作正式方法表现。
- 对既有五例task3，50k的真实后继max-V贪心与两个模型的max-Q网格贪心分别完成episode；100k V贪心复用既有结果。Q网格只调用原生learned Q，不用模拟器搜索评分，仍是诊断控制，不替代原生actor正式指标。
- 候选动作沿用121网格，Q/V两ensemble用max聚合，不挑有利ensemble。Q与actor都在同一环境实际执行，保存轨迹与完整结束状态。
- 仅对五个既有task3目标比较50k/100k起点的同0.2图下降可达性；保留离散化/吸附限制。100k场复用已验证缓存，不对已算结果重复做完整前向。
- 预定probe为这五例的起点，以及已保存100k actor轨迹第100步位置，共10个完整观测。对每个Q模型分别评分50k/100k actor动作与同网格最低Q距离，构成2×2交叉评分。actor相对网格差可能为负（连续动作优于离散网格），不截为零或称严格最优性差距。
- 同时记录min-Q距离减V距离，作为表示/值紧致性诊断；learned Q不是独立真值，不能将其差直接称最优Bellman误差。
- 诊断为post-hoc机制检查，不是新的独立验证，不证明哪个损失导致退化。若actor和Q控制都退化则不能只归咎actor；若Q控制仍有效而actor退化，则有策略提取不足证据。实际解释以全部完成结果为准。
