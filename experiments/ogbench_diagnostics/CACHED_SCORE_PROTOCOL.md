# 固定神经模型的精确输入缓存核验

2026-10-30，前两个物理批量阶段各按120秒上限退出，没有延长或恢复；均未完成全25例门槛，不能启用为正式工具。35组候选后继均逐位相同，已完成episode也相同，但仅改变物理调度仍不足以满足全量时限。本项新增精确神经评分缓存，不改变模型或物理语义。

- 仅用于固定QRL agent，encoder=None、JAX x64关闭、输入float32/float64。原jit函数实际将float64输入转换到float32，缓存键为完整形状及完整观测/目标转换到float32的字节；不是额外数值舍入或近似评分。每个miss仍直接调用原common.distances与原始输入。
- 每个键的首次hit重新调用原函数逐位核对，返回数组独立复制；LRU容量2048只影响命中率，不影响数值。每个agent独立缓存，训练中禁止复用或替换agent。完整episode仍执行全部真实env.step，所有候选物理与选中后继逐位检查照常保留；不以停滞提前终止。
- 先通过两个缓存方法测试。然后在全新cached_pointmaze_verification中，用不变的四线程物理实现完成原35组候选和原100k全部25例完整重放；观测/动作/距离/成功/步数与baseline逐位相同。复用前一阶段已保存35组候选数组，核对新旧物理代码摘要，再对缓存/原评分逐位核验；不重复旧基线训练/评价。
- 该新实现有独立120秒上限，不恢复两个已超时进程，不扩大各阶段上限。三个实现阶段累计上限360秒，必须披露此前两次超时。若任何值不等、缓存测试失败或未完成全部25例，不启用。
- 记录命中、首次命中重算、原函数调用与实际耗时。完整episode历史计时不是同热状态/并发负载基准，不把历史比值当严格提速倍数。通过只支持该固定状态任务/库/设备，后续新critic仍需自己检查实际选中后继。

不训练、不换seed、不启动1M，也不以评价器性能替代原研究目标。源码/测试/协议/报告提交，原始结果与失败/成功日志保留。
