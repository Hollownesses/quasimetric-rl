# E1：目标相关残差与官方 pair 价值损失的配对对照

冻结日期：2026-10-29。该协议在正式训练和任何处理组终点评价之前写出。

## 问题与假设

已完成的 navigate seed0 100k 官方 QRL 基线：task3=0/50，其他四任务各50/50。用户提供的既有诊断显示可达、有数据覆盖的出口走廊缺少网络距离下降通道。本轮不重复覆盖调查，检验直接改变 critic 的目标相关梯度能否改善距离排序和真实后继贪心执行。

从固定 params_100000.pkl（SHA256 397e919f2c453cee02ec840c615dce3532f31532fd639fbea6757c970fedbf0f）恢复两份完全相同的模型与价值模块 Adam 状态。

- A/pair：直接调用固定官方 commit 的 QRLAgent.value_loss。
- B/goal：保留 `100*softplus(5-d(s,g)/100)` 最大化项，把 `mean(relu(d(s,s_next)-1)^2)` 替换为 `mean(relu(d(s,g)-d(s_next,g)-1)^2)`。两个端点距离均参与梯度；同一目标 g；没有 stop-gradient target。
- 保留 eps=0.05、lambda 参数化与对偶更新公式、学习率3e-4、batch1024、官方全部网络及原始数据。
- 只更新 value 和 lambda；actor/dynamics 参数及 Adam mu/nu 逐位不变。移除 actor/dynamics loss，因此 A 是“官方价值损失续训”，并非官方端到端续训。
- 正式每组固定额外10,000次更新，训练采样seed2001，成对共享同一批数据和同一批 value_goals；不重采样处理组，不调参，不按 task3 提前停止、追加预算或挑选checkpoint。每500次记录两类残差；5k和10k保存；正式结果仅额外10k终点。
- 保留预训练 value/lambda Adam mu/nu 和100k计数，继续偏差校正。actor/dynamics 不经过 Adam，避免零梯度下旧动量改变参数。标量全局 Adam count 随 critic 增加，冻结模块的参数和矩不变。
- 固定 held-out validation batch（seed9001，2048条），与训练 RNG 分离。报告 pair/goal 两种平方正部、正残差比例、目标距离上坡比例、lambda、距离尺度和损失。仅在 held-out 统计上改善不构成成功。

## 评价（参考图和真实模拟器仅用于评价）

初始100k、A终点、B终点使用同一个固定评价库。每任务5个固定扰动（seed3100–3104；完整 MuJoCo integration state、goal、TimeLimit 计数），另保留用户描述的墙角坐标与目标作为场诊断锚点。不将任何参考最短路、成功轨迹或模拟器枚举数据输入训练。

- 主执行指标：每步枚举固定11×11动作网格，用真实 MuJoCo 后继的学到距离最小者执行；恢复完整 integration state 及 TimeLimit 计数；同一组候选动作、相同确定性 tie-break。遵循官方成功条件、1000步 TimeLimit，逐任务报告成功数和步数。
- actor冻结，故以相同状态调用 actor 应当完全一致；评价中同时核查这一不变量，不把 actor 成功率变化作为本轮成果。
- 参考图：间距0.2，动作每轴最大0.2，几何中墙体和球体半径来自环境；避障边沿段检查。到成功区域反向最短路径；同时计算最小峰值通路和严格下降可达性。若B改善，后续再以0.1及半径扰动核查稳健性。
- 报告整图和出口走廊的参考成本/网络距离排序、最短路下降边比例、下降可达比例、墙角最小峰值差及按距离IQR归一化的峰值差。峰值差不能单独判定成功。
- 对参考路线做真实 MuJoCo 执行验证，明确图是离散近似，不把成功任意路线当最优标签。

决策规则：B改善通道及执行而A不改善，支持目标相关梯度机制；A/B都改善则预算重要；仅残差改善而通道/执行不改善，则停止该约束改法，进入显式多步信号，不搜索该约束权重。单个checkpoint的结果不能称稳定改善；有益方向需要独立训练采样、初始化/检查点及完整预算基线核验。

## 方法边界

准度量三角不等式给出 `d(s,g)-d(s_next,g) <= d(s,s_next)`；所以B的残差逐样本不大于A，B同时改变梯度与可行集合。不能把收益完全解释为“同样约束的优化更好”。B依旧是上界约束，允许目标距离上坡，不保证下降通道。

进入多步时必须对照 MQE：其官方实现采用 state-action/state quasimetric、多步指数回报及价值提取，不能把任意行为累计成本等式称作最优距离，也不能把“给QRL加多步”称作新贡献。论文与代码：https://mqe-paper.github.io/ 。
