# E12：固定教师的任务无关查询扩展

2026-10-30，在E11提交c2e7c2b后冻结。E11随机验证RMSE约1.1，三个失败终点局部误差18.9–42.3，存在查询推广/排序缺口。本项只改变监督查询分布；不回填评价起点、目标、墙体或路线作训练标签，不继续延长E11。

## 唯一方法变量

复用E10全部固定图/距离和E11双向MSE、原100k IQE/value Adam/count/lr；冻结actor/dynamics/lam参数及矩。正式1000更新、batch256、官方采样seed2001不变，原始(s,s_next,value_goal)流须同E6/E11。E11作为未扩展对照，直接复用，不重训或重评。

每批偶数行保留原(s,g)，奇数行分别给完整二维s/g增加四维Sobol偏移，范围[-1,1]，不截断或过滤、不根据几何判定合法性。幅度1来源固定官方maze.py的noise=1、maze_unit=4、add_noise=uniform(-noise,noise)*unit/4；不是评价case噪声拟合。Sobol不scramble、无新随机seed，预生成2^18行，训练按顺序使用前128000行，扩展验证使用接下来1024行；原NumPy采样RNG不受影响。监督标签仅查询同一个固定教师的新(s,g)，不是对转移、动力学、未来目标语义的修改。原始s_next不变但本MSE不使用它；这些扩展点可落在物理不可达位置，教师给出的仅抽象查询先验，不能称真实MDP标签。

保留固定2048原验证集，另记录同验证行扩展后误差；两者都不决定预算或选模型。训练查询/目标流另哈希，与原采样流分开。教师、原模型和已有E11文件身份须核验。

## 执行、检查与出口

采样器测试覆盖原行和输入不变、幅度/完整坐标、可分块复现及不改变NumPy RNG；原loss/梯度/非零动量冻结测试直接复用E11既有通过证据。实际两步smoke保存加载，正式回到原100k/seed2001。每100步记录两种验证误差和原风险；终点count101000及完整agent/Adam/RNG往返、冻结模块/矩、同bank actor输出逐位核验。

总预算300秒含编译、训练、独立神经推理全部25例/完整1000步与canonical场；超时失败保留，不缩数据或扩预算。只保存固定1000终点，不选最好。沿用E11独立evaluate_neural.py（不导入图，无教师推理），原forward IQE+121真实后继、T1实际后继逐位核验。教师图只在训练使用，评价几何只在episode之后用于场。

门槛仍为task3五例全成功且保留原成功集。失败则不搜索幅度/比例/Sobol排列/lr/预算挽救，返回机制分析；通过也不宣称跨seed稳定或官方actor改善，随后另冻结策略利用检查。禁止换seed、1M或重启已停止程序。raw目录query_augmentation_1000，源码/测试/协议/中文报告/引用图逐实验提交，模型/JSON/CSV/NPZ/日志不提交。
