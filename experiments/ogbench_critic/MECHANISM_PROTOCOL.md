# M1：原始100k模型的距离上坡梯度分解

日期：2026-10-29；在任何本项数值结果之前写出。目的：直接检查训练信号在已知失败排序上的即时作用，不重复覆盖审计，也不查看E1的中间模型。

- 只加载严格哈希校验的原始100k checkpoint。每次反事实均从同一参数及Adam状态开始，不串联续训，不保存新模型。
- 固定32个独立抽样批次，seed4400，每批1024，沿用官方train GCDataset与随机value_goals。固定预算，不依结果追加批次或换seed。
- 固定probe：E0参考路线的第0与第15个节点，以及用户原诊断目标。两点由先前已复核路线确定；不输入训练。
- 两个被测量：距离差 `gap=d(peak,g)-d(anchor,g)`，以及局部尺度归一化 `gap / ((d(peak,g)+d(anchor,g))/2+1e-6)`。后者对统一正缩放不敏感，不能声称对任意变换不敏感。
- 分别求官方随机目标最大化项、原pair平方正部项（乘以原lambda）、目标相关平方正部项（同lambda）的value梯度。测量普通SGD的一阶probe变化 `-lr * dot(grad_probe, grad_loss_part)`；总梯度的投影可以相加，不能把这个投影等同于实际Adam结果。
- 对每批次另外测量真实A/B critic一次Adam更新后的probe变化及其一阶线性预测；仍从相同原始状态开始。测量零新梯度、仅继承Adam动量的参数变化作为参照。Adam有非线性预条件，不能将其反事实贡献做加法归因。
- 报告32批次的均值、标准差、正负比例和线性预测误差，不挑选有利批次。冻结actor/dynamics的参数和矩不变。
- 本检查只能定位原始模型附近的局部训练压力及梯度冲突；不能证明训练全程的根因，不能代替E1固定预算的终点场/执行对照，也不能用于修改E1预算、目标或权重。
