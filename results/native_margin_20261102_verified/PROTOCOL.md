# 原配方下的分支梯度压力诊断（运行前冻结）

只读 U-trap R0 50k 与 OGBench 官方 navigate seed0 100k；保持原模型、损失、乘子、优化器与采样器。不做持续训练，不保存反事实模型。原始输入由统一诊断的 SHA-256 清单校验。该项检验冻结点附近的训练压力，不能单独识别整个训练历史的原因。

1. U 使用全部 58 个多后继物理图源，去重按 (src,dst,cost)。按修订图参考 c+V 选择参考最佳动作，再选择成本最近的严格次优动作；同值按原记录编号。OG 使用原 50 个官方 task3 reset、完整模拟器状态与 11×11 动作网格。在 0.2 图参考最佳动作与最近严格次优动作间，按编号选择同时满足 0.1 图严格同序的第一对；无此对则排除并报告。两边都不按模型预测或成败筛选 probe。m=Q次优−Q最优，m>0 表示排对，排序容差 1e−4。
2. U 恢复 R0 终点 sampler，接下来的 32 个原 batch（上限 256，保留 epoch 尾批）固定重放，PHR 用原逐记录 λ、rho100，推远为 −.6 task−.4 B1。OG 复用历史 M1 的 seed4400、32×1024 原 GCDataset 批，原 softplus push、λ·mean(relu(dpos−1)^2)、dynamics 与 actor loss。报告 actor 到 value 的零梯度、分解与原总梯度一致性。两边采样单位保持各自原定义，跨环境不比较梯度绝对大小。
3. 对每个 probe、每个 batch 分别计算 −lr〈∇m,∇Lpart〉。正表示增加正确排序间隔。U 的 lr 使用终点 optimizer 实际 lr，OG 使用原 config lr。梯度投影可以相加。再从同一完整参数与 Adam 状态独立执行一次原生更新，测量真实 Δm；不串联这 32 次更新。保留零新梯度 Adam 动量对照，不能将 Adam 分量反事实相加。至少核验首批参数位移的一阶投影与真实差，保留非光滑/有限步误差。
4. 曝光描述：U 记录两后继作为物理源的副本数、参考最短后缀最低副本数，及 32 批中出现次数；OG 记录训练物理源到后继的最近欧氏距离、半径 .2 内源数量，以及 32 批中半径 .2 邻域出现次数。两者仅作各自支持度代理，不视为相同采样概率或精确覆盖证书。局部激活率按原 PHR 系数>0 / h>0 报告。
5. 同批次附加离线按源等权投影，不运行其参数更新：U 按精确 canonical src，OG 按固定 floor(x/.2+.5) 二维源箱；权重全局 N/(M*n_source)，不做 batch 内重归一。仅改变局部项权重，原推远/dynamics 保留。它检查原经验权重对局部纠正方向的敏感性，不能视作等效的原算法或跨环境同一干预。
6. 固定终点与全部 probe 均保留。按原先 m 正负分组，报告逐源 32 批均值、方向比例、总压力、Adam 实际变化、m/参考间隔、支持度。若支持度与间隔没有可比较的对错样本，明确标缺，不从相关性推导曝光因果。校验 checkpoint 前后 SHA、全量状态不变、重放 stream hash、分量投影闭合；数值表/NPZ/日志留本地，仅提交源码、测试、协议、报告和引用图片。
