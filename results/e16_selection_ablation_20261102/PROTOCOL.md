# E16 八候选目标选择消融 · 运行前冻结

复用原 seed0 的 E16 hard_goal_1000 与 E17-B；本轮仅训练一条 random8 线。E18 等更新与边权小图沿用历史结论。输出须全新，历史树只读。训练阶段不读评价轨迹、目标或参考路；预检可对输入文件只做 SHA 身份核对。记录固定终点及所有失败。

- 初态为官方 pointmaze-medium-navigate-v0 的 100k 完整 agent（包括 Adam、计数、JAX key），E10 固定 roadmap 教师、原 IQE 和 lr=3e-4。批 256，采样 np.seed(2001)，连续 1000 次原 E16 value-only 更新。偶数 128 行保留原查询；奇数 128 行复用 HardGoal.proposals 的源、Sobol 偏移、6302 个原型、stride 3895 和八候选。各列照旧算教师值与更新前网络的双向平方误差，原始行和所选行各 128 个进入原 iqe_distill.update。唯一更改为每个奇数行独立用 NumPy Generator(PCG64(20261102)).integers(0,8,dtype=int64) 均匀选列；不按误差加权，不用全局 np.random，不从八列都反传。smoke 后重建该 RNG。保留所有列选择、位置计数、训练流与池 SHA。
- 开跑前校验原 100k、教师文件、配置、实现、原训练/验证数据和历史终点；无参数更新重放 E17 两阶段批次身份。先实际两步 critic smoke，核对同一初始批的候选、标签及原 max 选择与现有实现，重载烟雾 checkpoint、检查冻结模块及 RNG。再从原 100k/原采样重新开始正式 1000 步。正式八候选池（含标签）、候选0、原始批次三字段流必须逐字节匹配 E16。
- 从 random8 critic 固定终点开始，原 E17 的 dynamics-only 1000 步，然后 actor-only 1000 步，batch256、lr3e−4、alpha0.0003、原官方损失与 Adam 状态。先各2步 smoke 并重置。正式提取重新 seed2001 一次，两个阶段之间不重置；三字段及含 actions/actor_goals 的五字段哈希均须与 E17 相同。验证 value/lam 冻结，逐阶段核对非活动模块及 Adam 矩和可重载性；固定 101000/102000/103000 三个完整 checkpoint，无中间选优。
- 评价冻结后一次。沿用统一诊断 50 个官方 task3 初始 integration/各自 goal、121 个真实后继、0.2 环境几何图与成功圆。按严格对汇总反序率（1e−4，并列单列），记录错选数、参考额外成本的全体与错选条件均值，逐起点配对。原验证集全部 100000 有效边上统计 h=d−1；沿 canonical 60 步环境图路线和 61 步真实重放统计 H、Στ、Στ/C，保留目标点末值并验证恒等式。E16 复用统一数表，另核对同输入计数/分数。复用 E16 在上述 50 例的真实后继贪心闭环；random8 同候选控制，每例最多 1000 步。
- 独立进程原 evaluate_extraction + 官方 evaluate，五任务各 50 例，顺序 1..5、np reset0、temperature0、gaussian=None、video0；沿用原接口附带的 25-case 直接 actor bank，与官方样本分开。每项公布 E17-B 相对 random8 配对新增和失去。逐回合核对原始观测、目标与评价随机流；保留新组实际 reset 状态与 action key 边界，历史 B 未记录的 key 按官方 task seed 及实际历史步数重建。不同终止步数允许之后的 key 偏移不同。两种控制器的成功均按各自真实回合计数，禁止把诊断贪心计入 actor 成绩。
- 预算以更新/样本/episode数固定，不因评价结果扩展或更换随机种子。每个评测回合有原 1000 步 TimeLimit；官方评测另设 1800 秒故障上限。可按已核验的完整阶段恢复工程故障，保留失败记录。主要导航判据为同输入官方配对成功数，主要排序判据为同 50 起点的严格对反序与参考额外成本。分项方向不同时分别解释，不以单个任务泛化。教师源自带几何及对称假设的数据 roadmap，教师误差不同于环境最优误差。只识别该初态、八候选、一次固定选择流与预算下的处理差异。
